## Genom (lessons — never deleted, only refined)

- **Never advertise numbers from self-generated data.** v1 claimed "+23 % vs LZMA" from synthetic repeats; one dataset (sensor) carried the whole lead, ties counted as wins, header overhead was subtracted ("netto"). On real files v1 was 20 % worse.
- **Compare against the strongest settings of the opponents** (xz -9e, zstd -19 --long, bz2), not weakened presets.
- **Independent blocks destroy context.** Splitting a 9.5 MB file into 128 KB blocks made it 2.4× bigger than plain xz.
- **A meta-compressor must include the best plain tools as candidates on the whole input**, otherwise it can lose to them.
- **`assert` is not validation.** `python -O` strips it; integrity checks must raise.
- **No compressor wins on all data** (counting argument). The honest promise: never worse than the best candidate + a few header bytes.
- **Contract first, then parallel work.** A binding SPEC let core, tests, benchmark and docs be built at the same time; blind-written tests passed against independently written code on the first merge.
- **Verify every reviewer finding.** Of 10 review findings, 3 were false (lc/lp/pb "invalid", hash-seed "nondeterminism", "broken" bench), 1 was a real bug.
- **Benchmarks in CI must not depend on third-party hosts** (Canterbury: 403 for GitHub runners). Vendor small pinned data.
- **A red CI that nobody looks at is no CI.** v1's workflow was invalid YAML for 8 months.
- **Check the shell before sending prompts through it:** unquoted heredocs execute backticks inside prompt text.
- **A memory cap must never make a valid stream undecodable.** Bound the hostile case; size codec state to what the stream needs. LZMA needs its dictionary next to the output, so "cap + 64 KiB" was an impossible promise — the spec now says 2·cap.
- **Small test files hide large-file bugs.** 281 green tests and a green Canterbury CI missed three decoder bugs that only the 51 MB mozilla file showed. Every decoder change needs a roundtrip > 8 MiB per codec variant, not just the winning one.
- **Never guess codec defaults.** "No dict_size → 8 MiB" was wrong for preset 9 (64 MiB); take values from the library or a table tested against it.
- **State the trade-off next to the number.** `fast` is 8.6× faster and 24 % larger; a speed figure without the size cost is advertising.
